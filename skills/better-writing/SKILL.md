## Scope, so it doesn't get confused with this library's own voice rules

This covers product copy inside the project being built: button labels, error messages, empty states, onboarding. It has nothing to do with how an agent talks in this library, which is [tai-protocol](../tai-protocol/SKILL.md)'s Language section, always in effect regardless of what project is open. Load this skill for the words a user of the project will read; keep tai-protocol for the words the agent writes in chat, commits, or comments.

# design-md: recurring feedback pipeline

**Considered:** 2026-11-02
**Decision:** declined
**Why:** Vercel collects feedback weekly from Slack, GitHub, and Figma, groups repeated complaints with automation, and has a person route each proposed change. That process needs a team producing enough feedback to group, which personal projects don't have. [design-md](../../skills/design-md/SKILL.md)'s revise mode covers the useful part: routing corrections into rules when the user brings them.
**Revisit if:** A team project starts producing repeated design feedback across several channels.

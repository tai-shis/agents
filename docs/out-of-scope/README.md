# Out-of-scope log

A record of skill ideas or expansions that were considered and deliberately declined, so the decision doesn't get re-litigated when the idea resurfaces. Not a skill, not part of the catalog: a plain note per entry.

One file per declined candidate: `docs/out-of-scope/<slug>.md`.

```markdown
# <candidate name>

**Considered:** <date>
**Decision:** declined
**Why:** <the actual reason, e.g. redundant with an existing skill, too narrow to reuse, or the triggering task was one-off>
**Revisit if:** <what would change the answer, if anything>
```

Referenced from [skill-creator](../../skills/skill-creator/SKILL.md) when a candidate skill doesn't earn its place, and from [tai-reflect](../../skills/tai-reflect/SKILL.md) at the one-off level of its durable-home ladder.

# make-interfaces-feel-better

**Considered:** 2026-10-02
**Decision:** declined
**Why:** Jakub Krehel's earlier, standalone skill at [jakubkrehel/make-interfaces-feel-better](https://github.com/jakubkrehel/make-interfaces-feel-better), linked from [jakub.kr/skills](https://jakub.kr/skills) as "installed separately." Its own README calls it the "lightweight predecessor" to his main `skills` collection, and its content (animations, typography, icons, surfaces, performance) is a strict subset of what [better-ui](../../skills/better-ui/SKILL.md) and [better-typography](../../skills/better-typography/SKILL.md) already cover, vendored from that same author's current collection. Carrying both would mean two skills firing on overlapping triggers with no way for an agent to know which one is current.
**Revisit if:** The author updates this predecessor with content that's no longer a subset of `better-ui`/`better-typography`, or stops maintaining the main collection and this becomes the current version again.
